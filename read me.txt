小积木 BlockQuiz — 字体抽离版 使用说明
==========================================

【目录结构（必须保持）】
  小积木_BlockQuiz.html   ← 主文件（约 2.7MB）
  fonts/
    ├ han.woff2           ← 霞鹜文楷（汉字，约 8.4MB，OFL 可商用）
    └ py.woff2            ← LxgwPinyin（拼音，约 16KB，OFL 可商用，单层ɑ）

【怎么用】
  HTML 和 fonts/ 文件夹必须放在一起（HTML 同级目录下有 fonts/ 文件夹）。
  本地预览：双击 HTML 可能因浏览器安全策略不加载本地字体，
           建议用本地服务器（如 VS Code Live Server）或直接部署到网站。
  网站部署：把 HTML 和 fonts/ 一起上传到同一目录即可。

【字体抽离只影响字体显示，不影响任何其他功能】
  万一 fonts/ 没跟上 → 字体回退系统默认（楷体变普通字体、拼音可能变双层a），
  但所有功能（题卡、题卷、拼音数据、导出、交互）完全正常。

【以后继续改 HTML】
  字体文件是不变的配套资源，改 HTML 时完全不用动 fonts/。
  最终定稿时，把最终 HTML + 这个 fonts/ 文件夹一起发布即可。

【以后换/加字体】
  换字体：把 fonts/ 里的文件同名替换，HTML 不用改。
  加字重：往 fonts/ 加文件 + HTML 加一行 @font-face。
